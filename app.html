      Sync from Google Calendar

      Live two-way sync

      not set up

      Playday reads your Google events on every sync and writes back the events you add, edit or delete here. It needs an OAuth Client ID from your own Google Cloud project — that's a one-time, five-minute setup, and no server is involved.

      How to get a Client ID
      1. Open Google Cloud Console, create a project, then enable the Google Calendar API under APIs & Services.
      2. Go to APIs & Services → OAuth consent screen, choose External, and add your own Google address as a test user.
      3. Under Credentials → Create credentials → OAuth client ID, pick Web application and add this page's origin (for example http://localhost:8080) to both Authorised JavaScript origins and Authorised redirect URIs.
      4. Copy the Client ID (ends in .apps.googleusercontent.com) into the field below.

      While the consent screen is in Testing, Google expires refresh sessions after 7 days and only test users can connect. Fine for a personal calendar; publish the app if you want it permanent.

      It also syncs the moment you come back to the tab. Google access tokens last an hour, so after that Playday asks for one tap to reconnect.

      Import an .ics file

      no setup

      In Google Calendar: Settings → Import & export → Export, unzip it, then drop the .ics files here. They arrive read-only, coloured per calendar, and dropping the same file again refreshes it.

        Download everything in Playday as one .ics file, then use Google Calendar's Import to pull it in.
